Side panel

Type any URL in the bar above and press Enter to load it here.

Handy while developing

  • http://localhost:3000 — a dev server in a terminal tab
  • /health — this workbench's health route
  • https://<app>.<your-zone>/ — another openhost app

Controls

  • Drag the divider to resize; double-click it to reset.
  • Focus it and use ← → (hold Shift for bigger steps).
  • ↻ reload, ↗ open in a browser tab, × hide.
  • Bring it back with ◻ panel in the tab bar.

Width, visibility and the last URL are remembered in this browser. Turn the whole panel off again with /side-by-side in Claude Code.
