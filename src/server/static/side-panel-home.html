A server running in this container

  • /absproxy/5173/ — port 5173, for a server started with that base path (vite --base /absproxy/5173/)
  • /proxy/8000/ — port 8000, prefix stripped, for simple servers with relative links
  • localhost here means your own machine, not the container.

Elsewhere

  • https://<app>.<your-zone>/ — another openhost app

Controls

  • Drag the divider to resize; double-click it to reset.
  • Focus it and use ← → (hold Shift for bigger steps).
  • ↻ reload, ↗ open in a browser tab, × hide.
  • Bring it back with ◻ panel in the tab bar.

Width and visibility are remembered in this browser. Claude can point this panel at a server it starts — just ask it to show you. Turn the whole panel off with /side-by-side.
